# LUCAS

This project provides a Python-based AI engine for preprocessing, feature extraction, matching, geometry, registration, evaluation, and pipeline orchestration.

## Structure

- `ai_engine/` - core package modules
- `data/` - raw, processed, and result datasets
- `experiments/` - experimental scripts and notebooks
- `notebooks/` - Jupyter notebooks
- `tests/` - unit and integration tests

## Getting started

1. Create a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start developing in the `ai_engine` package.

## Package modules

- `ai_engine.preprocessing` - preprocessing utilities
- `ai_engine.features` - feature extraction and descriptors
- `ai_engine.matching` - matching logic
- `ai_engine.geometry` - geometric computations
- `ai_engine.registration` - registration workflow
- `ai_engine.evaluation` - evaluation metrics
- `ai_engine.pipeline` - orchestration pipeline
